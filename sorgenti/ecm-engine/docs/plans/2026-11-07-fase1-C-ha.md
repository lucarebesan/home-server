- [ ] Step 3: `deploy_ws.py` – save the built JSON through the WebSocket without restarting HA. It runs inside the HA container (aiohttp is available there):
```python
"""Uso: docker exec -i homeassistant python3 - < deploy_ws.py  (con CONFIG_JSON e TOKEN in env)."""
import asyncio, json, os
import aiohttp

async def main():
    cfg = json.loads(os.environ["CONFIG_JSON"])
    async with aiohttp.ClientSession() as s:
        async with s.ws_connect("http://127.0.0.1:8123/api/websocket") as ws:
            await ws.receive_json()
            await ws.send_json({"type": "auth", "access_token": os.environ["TOKEN"]})
            assert (await ws.receive_json())["type"] == "auth_ok"
            await ws.send_json({"id": 1, "type": "lovelace/config/save", "url_path": "ecm-v2", "config": cfg})
            print(await ws.receive_json())

asyncio.run(main())
```
Launch from the Mac, without the token ever crossing the command line on the Mac (`$(cat ...)` expands on the server):
```bash
scp build/ecm_v2.json deploy_ws.py home@192.168.1.100:/tmp/
ssh home@192.168.1.100 'docker exec -i -e TOKEN="$(cat ~/.config/ecm/ha_token)" -e CONFIG_JSON="$(cat /tmp/ecm_v2.json)" homeassistant python3 - < /tmp/deploy_ws.py; rm /tmp/ecm_v2.json /tmp/deploy_ws.py'
```
(adapt the JSON path to what `build.py` actually produces; if `CONFIG_JSON` is too long for an env var, `docker cp` the file into the container `/tmp` and read it from there). Expected: `{"id":1,"type":"result","success":true,...}`. Before saving, back up the current config with `lovelace/config` (`{"id":1,"type":"lovelace/config","url_path":"ecm-v2"}`) to `~/backup-ecm-v2-<timestamp>.json` on the server.
